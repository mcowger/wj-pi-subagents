# `/agents` 面板与子代理详情面板响应式尺寸规格

## 背景

`/agents` 面板与子代理详情 overlay 共用一个固定外框配置：请求宽度 160 列、四周各 1 列边距，正文高度固定（树面板 12 行、详情面板 20 行）。大终端中面板四周留白明显，垂直方向也无法显示更多代理项或活动记录。

## 目标

两个 overlay 在打开与 resize 时都占满扣除固定边距后的可用终端空间，并随可用高度显示更多内容；样式、换行、滚动、选中状态、快捷键与打开/关闭交互保持不变。

## User Stories

1. 作为在大终端中使用 `/agents` 的用户，我希望面板占满扣除边距后的可用空间，以便减少四周留白。
2. 作为在大终端中查看子代理详情的用户，我希望详情面板同样占满可用空间，以便看到更多活动记录。
3. 作为运行期间调整终端大小的用户，我希望面板随 resize 自动适应宽度与高度，以便无需关闭重开。
4. 作为在窄终端中工作的用户，我希望面板继续由宿主按可用空间钳制，以便内容不超出终端边界。
5. 作为项目维护者，我希望尺寸行为由聚焦测试覆盖，以便后续重构可以发现用户可见回归。

## 范围

- `AGENT_TREE_OVERLAY_OPTIONS`（`src/agent-tree-ui.ts`）改为 `width: "100%"`、`maxHeight: "100%"`、`anchor: "center"`、`margin: 2`；两个 overlay 继续共用同一配置，保证同尺寸策略。
- 正文行数响应式：终端行数 − 上下边距（2×2）− 框线装饰（6）；宿主未暴露终端行数时保持模型当前视口行数，极小终端只保底 1 行避免空输出。
- `AgentTreePanelModel` 与 `AgentActivityViewerModel` 各新增 `setViewportHeight(height)`：非法输入忽略，调整后选中与滚动（含跟随）收敛到新范围。

## 非目标

- 不调整内部信息架构、字段、样式、换行与交互语义；只改变外框尺寸与可见正文行数。
- 不为极小终端增加特殊处理；保底 1 行仅用于避免空输出。
- 不修改 Pi 宿主依赖、常驻 agents widget、RPC widget 或其他无关模块。

## Implementation Decisions

- 宽度与高度使用宿主原生 `SizeValue` 百分比解析：`compositeOverlays` 每次渲染都按当前终端尺寸重新解析并钳制到可用空间，静态 `"100%"` 即可跨 resize 响应，无需动态 `overlayOptions` 函数。
- 宿主只向组件传 `render(width)`，不传高度；组件经 `tui.terminal.rows`（宿主 `TUI.terminal` 公开只读视图）获取终端行数，测试桩可省略该视图。
- 宿主会把超出 `maxHeight` 的输出裁剪；组件按可用高度精确渲染（正文 + 6 行框线装饰），因此不会被裁剪。
- 正文行数变更走模型 `setViewportHeight` 而非重建模型：选中节点、展开集合、滚动语义与跟随规则全部保持。
- 不新增配置项、快照字段、协议字段或持久化数据，不改变 Pi overlay 接口契约。

## Testing

- overlay 配置断言：打开 `/agents` 捕获 `width: "100%"`、`maxHeight: "100%"`、`anchor: "center"`、`margin: 2`（`test/agent-tree-ui.test.ts`）。
- 高度链路断言：测试桩提供 `terminal.rows = 30`，组件渲染输出 26 行（正文 20 + 框线装饰 6）；未提供终端视图的既有用例保持默认视口高度。
- 模型级断言：`setViewportHeight` 扩展/收缩后正文行数随之变化，选中节点保持可见，滚动与跟随正确夹紧，非法输入忽略（树面板与查看器各一例）。

## Current State

- 实施前：外框请求宽度 160、四周 margin 1、正文固定 12/20 行。
- 实施后：外框请求可用空间（`"100%"`/`"100%"`）、四周 margin 2、正文行数随终端高度响应式变化。
