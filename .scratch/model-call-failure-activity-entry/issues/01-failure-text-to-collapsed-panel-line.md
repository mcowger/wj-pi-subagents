# 01 — 失败文本贯通到面板折叠行（契约升版）

**What to build:** 子代理的一次模型调用以错误收尾时，父会话用户在该子代理的活动面板里看到一行红色 `▸ × Error: <错误文本首行>`。条目按"每次失败尝试一条"登记、逐条保留，且不改变该子代理的生命周期状态。本条同时把规范活动契约与监督协议版本各递增一位，让新的"模型调用失败条目"在产生端、接收端、活动缓存与查看器四处一次就位；条目一次定死四个字段（收尾原因、错误文本、provider、model），避免后续为展开体二次升版。设计依据见同目录 `spec.md`。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 正文为空、收尾原因为错误且带错误文本的收尾消息，在该子代理的活动面板渲染出一行 `× Error: <错误文本首行>`
- [ ] 该条目以"模型调用失败条目"的独立身份进入活动缓存，按到达顺序出现且可被回放
- [ ] 条目完整携带收尾原因、错误文本、provider 与 model 四个字段（展开体由 02 号票消费）
- [ ] 规范活动契约版本与监督协议版本各递增一位，既有版本断言同步更新
- [ ] 版本一致时，新条目在发布侧与接收侧都被接受，不产生无效帧、不使通道进入故障
- [ ] 模型调用失败条目不触发任何生命周期状态转换，该子代理的运行状态与失败前一致
- [ ] 既有三种活动条目（消息、父消息、工具）的行为与渲染完全不变
